# baisón — единая система для бизнеса «отопление и вода»

Заменяет связку **amoCRM + «Прополис» + 1С** одной системой:
CRM (заявки, воронка, задачи, клиенты), контроль команды «Прополис»
(сотрудники, смены, отметки прихода/ухода), каталог товаров с остатками,
счета-оценки и заказы, интеграции с amoCRM и 1С.

Фирменный стиль: палитра компании (антрацит / тициановый / белый) + логотип baisón.

Сфера: котлы, сантехника, санфаянс, плитка, насосы, трубы, мелочовка
и монтаж.

## Возможности

| Модуль | Что делает |
|---|---|
| CRM | Заявки (лиды) с этапами воронки: новый → связались → посчитали счёт → переговоры → сделка/срыв. Задачи (звонок, встреча, доставка, монтаж). База клиентов + полная карточка клиента (заявки, заказы, счета, задачи в одном месте). |
| Лиды из соцсетей | Публичная форма `/lead?source=tiktok` для ссылки в bio Instagram/TikTok; webhook `/webhooks/lead` для агрегаторов (360leads, Telemost, Parsegram…). Квалификация лида: что ищет, бюджет, сроки, кто решает → горячий/тёплый/холодный. |
| Автопилот заявок | Карточка лида заполняется сама: телефон нормализуется, из свободного текста определяется категория (котлы/насосы/сантехника/плитка/трубы/мелочь + монтаж), бюджет («50к», «150 тыс»), сроки («срочно», «просто смотрю») и кто решает (сам/семья/компания). Автоматически назначается менеджер с наименьшей загрузкой и создаётся задача «Позвонить». Заполняются только пустые поля — ручные данные не затираются; всё автозаполненное помечено «⚡ авто». Отключается `AUTOPILOT=0`. |
| Команда («Прополис») | Сотрудники (должность, график, часы смены), отметки «пришёл/ушёл» с автоопределением опоздания (допуск 15 мин), отчёт за 7 дней: опоздания и отсутствия. Доступ: admin/manager. |
| Каталог | Товары (артикул, бренд, категория, цена, себестоимость, мин. остаток), склады/точки, приход/списание/корректировка с журналом движений. |
| Продажи | Счета-оценки (дедлайн, статусы, «в заказ» в один клик), заказы с позициями (товар или услуга, скидка), отгрузка **автоматически списывает остатки**, закрытие заказа закрывает заявку как сделку. |
| Отчёты | Главный экран: открытые заявки, задачи, заказы, товары ниже мин. остатка. |
| Пользователи | Роли: admin / manager / cashier, блокировка, управление админом. |
| Интеграции | Выгрузка сделок из amoCRM → заявки; номенклатура и остатки из 1С → каталог. |

## Запуск

```bat
py -m pip install -r requirements.txt
copy .env.example .env   :: заполнить ключи amoCRM/1С (можно позже)
py wsgi.py               :: dev-режим (debug, автоперезагрузка)
```

Открыть http://127.0.0.1:5000 — логин **admin**, пароль **admin123**
(сменить после первого входа: создать своего админа в «Пользователи»,
старого заблокировать).

**Продакшен (Windows):** `run_prod.bat` — waitress, без debug.
**Продакшен (Linux-хостинг):** gunicorn + nginx:
`gunicorn -b 0.0.0.0:5000 --workers 2 "wsgi:app"`.
База — PostgreSQL: в `.env` задать `DATABASE_URL=postgresql+psycopg2://user:pass@host/teplodom`
(схема создаётся автоматически; перенос с SQLite — `py migrate_pg.py`).

## Настройка интеграций (.env)

**Схема приёма лидов из Instagram/TikTok** (официальных API для DM/комментариев в РФ нет):
- **Ссылка в bio** → `https://ваш-сайт/lead?source=tiktok` (или `instagram`) — форма без логина, лид и карточка клиента создаются сами.
- **Агрегаторы комментариев/DM** (360leads, Telemost, Parsegram, BotsHelp и т.п.) → `POST /webhooks/lead` с заголовком `X-Webhook-Token: <WEBHOOK_TOKEN>`. Тело JSON: `{name, phone, email, source, need, comment, utm_*}`.

**amoCRM** — ключи из amoCRM → Настройки → Настройки → API.
`AMOCRM_PIPELINE_ID` — id воронки (видно в адресе amoCRM или через API
`GET /api/v4/pipelines`). При импорте этап amoCRM маппится по названию
(«сделка/оплачен» → сделка, «срыв/отказ» → срыв и т.д.) — правила в
`app/integrations/sync.py::_amocrm_stage_to_status`.

**1С** — нужен REST Web Services, настроенный на стороне 1С. Ожидается JSON:
- номенклатура: `[{"sku": "K-100", "name": "Котёл 24 кВт", "price": 5000}, ...]`
- остатки: `[{"sku": "K-100", "qty": 5}, ...]`

Пути указываются в `ONES_CATALOG_PATH` / `ONES_STOCKS_PATH`.
Возможные ключи в JSON: `sku|article`, `name|naimenovanie`, `price|tsena`,
`qty|ostatak` — смотрите `app/integrations/sync.py`.
Для выгрузки документов (счёта) в 1С заложена отправка XML
(`OneCClient.push_document` + `ONES_DOC_PATH`).

## Структура

```
app/
  __init__.py         фабрика приложения, dashboard, сид данных
  config.py           настройки (env)
  models.py           модели домена
  utils.py            номера документов, парсер позиций
  auth/               вход/выход, роли, пользователи
  crm/                заявки, воронка, задачи, клиенты; autopilot.py — автозаполнение карточек лида
  public/             публичная форма /lead и webhook приёма лидов
  hr/                 «Прополис»: сотрудники, явки, отчёт
  catalog/            товары, категории, склады, движения
  sales/              счета, заказы, списание при отгрузке
  integrations/       клиенты amoCRM/1С, синхронизация
tests/                pytest: домен, маршруты, интеграции (мок API)
```

## Дорожная карта (следующие шаги)

1. **Доработки «Прополиса»** — автозапись отметок (GPS/веб-часы/Wi-Fi), уведомления опозданий в Telegram, учёт переработок, график по месяцам.
2. Обратное направление: создание сделки в amoCRM из заявки (роботы/комментарии).
3. Выгрузка счёта/заказа в 1С (XML-документ) и статус оплаты из 1С.
4. Воронка-канбан, уведомления, история действий по заявке.
5. Печатные формы (PDF) счетов-оценок, экспорт в Excel.
6. Отчёты: выручка, средний чек, конверсия, дебиторка.
7. Заглушки под источники заявок: Avito API, сайт-витрина, Telegram-бот.
8. Автозапуск синхронизаций (планировщик) + логи синхронизаций в БД.
9. Умный автопилот лидов: разбор текста через LLM (пока — словари/регулярки), Telegram-уведомление менеджеру о новом лиде, авто-создание задачи «Посчитать счёт» после звонка.
